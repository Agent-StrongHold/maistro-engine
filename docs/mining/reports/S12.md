  - **Core redesign**: Engine normalizes effective_cost to [0, 1] within in-budget range using _COST_CEIL = 1/ln(2) ≈ 1.44

  - **Engine formula** (line 117): `q_factor / (1.0 + norm_cost)^cost_weight` — normalized cost with +1.0 offset to prevent division-by-zero and create interpretable range [1, 2+]
  - **Stronghold return**: Always returns ModelCandidate (line 23)

  - **Cost normalization rationale** (lines 3-18, 39-56 engine): 
    - Maps raw cost ∈ (0, ~1.44] to [0, 1]
    - Over-quota models (cost >1.44) get penalty: 1.0 + (cost - 1.44)
    - Enables meaningful comparison between huge budgets (cost≈0) and nearly-exhausted budgets (cost≈1.0)
  - **Impact**: Engine is more robust to provider budget variance; Stronghold treats all in-budget equally
  - **Risk**: Stronghold can select expensive models early; engine defers them until budget exhaustion triggers penalty
